# Immagini del README

- `banner.svg`: illustrazione vettoriale del progetto; il grafico è decorativo.
- `dashboard.png`: screenshot dell’interfaccia desktop a 1440 × 1229 pixel.
- `energy.png`: screenshot del pannello energetico della stessa interfaccia.

Gli screenshot sono stati acquisiti con Chromium tramite Playwright usando l’HTML, il CSS e il JavaScript del progetto. Le risposte di `/api/stats` contengono dati dimostrativi: hostname, attività, sensori, energia e costi non provengono da un server reale. Non sono benchmark né risultati di un’installazione di produzione.

La documentazione non aggiunge dipendenze all’applicazione e non include credenziali o dati privati.
